# Destination outline graphics

Neutral decorative outlines derived from this repository's `us_county_boundaries.geojson`, grouped by the STATE property, dissolved and simplified by 0.025 degrees during a one-time local build. Exterior rings are retained. Includes 50 states, DC and Puerto Rico. Runtime rendering uses bundled JSON and ReportLab, not an external image provider or AI.

These are not official seals, precise navigation maps, evidence of government endorsement or risk indicators. The underlying county file's source vintage was not independently reverified for this graphic update. Alaska longitudes are unwrapped across the date line for display. Destination selection uses the existing ZIP lookup's state abbreviation; no state is guessed from an unresolved ZIP. Unknown/unsupported jurisdictions omit the graphic.
